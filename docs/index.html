How this maps to the real binary

  • Combat / Players / Visuals / Misc write into GlobalConfig — same fields the C++ threads read every tick.
  • Execute calls Executor::SetSource → Bridge::Send(ExecScript) when the DLL is injected.
  • Execute + UNC prefixes bootstrap + selected UNC stubs, then sends one payload.
  • AI helper is local templates (esp / speed / fly / noclip / teleport) — no network.
  • This page is a simulator. It does not attach to Roblox.
